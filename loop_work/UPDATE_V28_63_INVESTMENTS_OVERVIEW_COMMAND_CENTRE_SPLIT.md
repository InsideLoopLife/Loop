# v28.63 — Investments overview / command-centre split

## What changed

- The Investments tab now lands on an overview-only page.
- The overview keeps the top pensions/investments hero and larger spending-style summary cards.
- Pension and investment cards open their own immersive command-centre experiences.
- Pension and investment snapshot cards open the normal detailed breakdown rather than the command centre.
- Investment command centre now includes a household-member avatar-only multi-select filter.
- The command centre can be filtered by one member, multiple members, shared pots, or the whole household.
- The investment command centre keeps the amplified visual dashboard, scrolling ticker, dotted cost line, glowing chart line, diversification notches and holdings rows.
- The pension command centre gives a dedicated pension-focused landing view with member filters, pot count, fund count and DB scheme count.

## Database

No schema changes. A no-op migration is included for version tracking.
